# Worked examples

Worked examples are intended to test and refine the conceptual model before software implementation.

## Planned primary cases
1. HadUK-Grid bounded variable/version/use case.
2. NRFA-style hydrometric time series.
3. Riverfly RMI bounded citizen-science biological observation case.

## Planned challenge cases
- Abstraction/use data at a resolution inappropriate to a finer-scale use.
- Shared or protected water-utility data.

Each example should include:
- assessment target;
- intended use statement;
- evidence inventory;
- criteria assessed;
- criterion results and evidence bases;
- items requiring domain judgement;
- specific-use requirement verdicts;
- improvement actions;
- reviewer disagreements/notes.
