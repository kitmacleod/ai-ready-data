# Licence note

A final licence split has not yet been adopted.

Before external contributions are accepted, the project should decide and document licences for:

- specification and documentation text;
- schemas and examples;
- future software.

A candidate pattern to review remains **CC BY 4.0** for documentation and **Apache-2.0** for code/schemas. This is **not** an adopted project decision in v0.2.1.

Until a licence decision is recorded, this repository checkpoint should not imply permissions beyond those already attached to its external source material.
