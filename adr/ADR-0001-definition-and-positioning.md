# ADR-0001: Define AI-readiness independently and build on existing community work

**Status:** Accepted for v0.2.0 Working Draft  
**Date:** 2026-11-04

## Context
Several established initiatives address AI-ready data, notably ESIP for environmental/Earth science and ODI more generally. Defining AI-readiness as conformance to this project's own specification would be circular and would risk creating a competing checklist.

## Decision
Define AI-readiness independently of the project specification. Position the project as a water/environmental operationalisation and use-fitness layer that reuses existing community standards and guidance wherever adequate. ESIP v1.1 is the primary baseline for generic environmental AI-readiness questions.

## Consequences
- The project crosswalks before inventing criteria.
- New criteria require a documented residual gap.
- Claims of novelty are restricted to features not already provided elsewhere.
